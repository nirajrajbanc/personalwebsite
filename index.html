About

I got into IT the way most enthusiasts do — by taking something apart to see how it worked, and then needing to know how everything else worked too. That curiosity turned into a habit of learning systems administration, networking, and software, one project at a time.

These days I split my time between hands-on labs — setting up servers, configuring networks, poking at security — and writing code to automate the parts that shouldn't need to be done by hand twice.

I'm based in Nepal and I like documenting what I learn, partly so I remember it later, and partly because someone else searching the same error message at 2am might need it too.
